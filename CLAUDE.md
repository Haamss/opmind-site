# OpMind Site — Contexte pour Claude Code

## 🧭 CAP STRATÉGIQUE — À RESPECTER AVANT TOUTE TÂCHE

**Avant toute tâche, la classer : sert-elle (1) le carnet réglementaire, (2) la boucle instructeur↔tireur, ou (3) la monétisation ? Si non → backlog, sauf bug bloquant le launch. Signaler immédiatement toute dérive de scope hors de ce cap.**

### Réalité assumée
- Solo, temps partiel, launch cible septembre 2026.
- B2C français = arithmétiquement borné (~50-80k€ ARR max) : canal de crédibilité, pas de revenu.
- Le revenu réel dépend d'UNE variable : contrat institutionnel PIA-207 (Hexablock). Prérequis bloquant NON technique : autorisation hiérarchique.
- Le code ne déplace pas les probabilités. L'autorisation hiérarchique et le premier RDV institutionnel, si.

### Les 3 manques qui génèrent du revenu — TOUT LE RESTE EST SECONDAIRE
1. **Carnet réglementaire** — n'existe pas. PIA-207 (militaire, priorité 1), FDO (3 séances/12h annuel), registre club civil. Champs : munitions, arme, type de séance, validation instructeur, export officiel. Démontrable avant fin 2026 pour un RDV institutionnel.
2. **Boucle instructeur↔tireur robuste** — un seul lien réel aujourd'hui. À éprouver end-to-end multi-comptes (assignation → séance → feedback → validation) AVANT de construire le carnet dessus.
3. **Monétisation minimale au launch** — au moins un paywall simple (dashboard instructeur). Une app gratuite fait des stats, pas du revenu.

### Manques importants (après les 3 critiques)
Analytics de progression · pivot séances/templates (modèle de données, import, bibliothèque) · onboarding · iOS · Competition/IPSC = PAS prioritaires.

### Règle produit
Ne PAS ajouter de modules de training : déjà au niveau des concurrents. Le manque n'est pas là.
